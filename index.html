当我到20岁时，我在想些什么

发表于 2026-08-03 更新于 2026-08-04 分类于 随笔 本文字数： 813 阅读时长 ≈ 1 分钟

再过不到两个小时，我年龄的数字在统计学中就是20了，一个整数。而整数总是有纪念意义的，所以我觉得自己得写点什么。回顾我这20年，前十年基本属于未开智状态，而后面十年也大部分处于受教育阶段。一是没有什么拿得出手的成就，二是自己的思想也确实没有完全成熟，所以真的不知道该如何评价。总的来说我这20年算是平稳度过了，既然没有什么苦难可以铭记，那就写写20岁的我都在想些什么吧。

20岁的我会想些什么呢？其实意识到自己已经20岁了还是有点难以置信的，在我的印象里20岁已经完全是社会人了，但我现在感觉自己还处于适应阶段。所谓“大人”平时做的上班、开车、做饭之类的事情，我都已经经历过了，但是这些还远远没有融入我的日常生活。我可能还是没有完全意识到我已经长大了，开始拥有社会地位了，内心还是没有接受我马上要变成社畜的现实。不过照例还是要感慨一下时光的飞逝，记得小学的时候还一直盼望着到18岁就能自由了，现在居然已经20岁了，都开始奔三了。可惜的是以前想象中的很多事都没有做到，或者是根本没有那么美好，所谓的自由并不是嘴上说说那么简单。总感觉20岁听起来就和18、19岁不一样，仿佛有某种质变。但是现在的我和17岁的我又有什么本质上的不同呢？我不明白。总感觉现在的大学生活就像在逼着刚高考完的学生快速适应社会，然后不管你有没有适应就扔到社会里历练，所以我时常感觉我身边的大部分人其实都是迷茫的，无非是有没有表现出来，而我也一样。

20岁的我能想些什么呢？无非就是在学习和打游戏之外，苦恼于处理麻烦的人际关系，努力社会化。依旧是充满对未来的莫名的担忧，再就是总想多凑点项目，顶着实习压力想办法让自己多玩几天罢了。那20岁之后的我呢？能够享受大学生活的日子也真的不多了，后面只能出到社会上再去适应了。后面的十年很可能就是我人生中最重要的十年了，希望我能交出一份令自己满意的答卷。至少也要让我的下一个十年回顾有东西可写吧。

最后，祝我20岁生日快乐。

随便写点

发表于 2026-05-26 更新于 2026-08-03 分类于 随笔 本文字数： 547 阅读时长 ≈ 1 分钟

突然发现博客已经快一个月没更新了，还是随便写点东西吧。说到底这个网站是我vibecoding的产物，也就是我练习使用ai，了解如何搭建网站的试验品。通过完善这个网站，我也亲身体会到了ai的迅猛发展与局限性，也大概知道前端是个什么东西了。要说对我专业水平有什么提升，大概是没有的。但我至少会在github上搭项目了，也算是一大进步。要问我为什么想要搭网站，不为什么，就是觉得有自己的网站是个很牛逼的事。现在大部分人都没有，而我有，真是太小众了😋当然，我搭建个人网站也是希望在互联网有一片自留地，而不会受到各大平台的限制。

刚开始写博客的时候确实是兴致满满，一点点的改界面布局，增加网站功能。但是现在都完善的差不多了，反而就放在一边渐渐淡忘了。而我又总是怕麻烦，即使有时候突然有好的点子想写下来，想了想又觉得挺麻烦的就没有行动。果然人除了强制执行就只有兴趣驱动了，也就是三分钟热度。但至少我不会忘了这个网站，再怎么说也不会让它这么早就被扫进互联网的垃圾堆里。至于到底有没有人会看，我也无所谓。反正我短期内不会加评论之类的功能，有没有人看我也不知道。想写啥写啥，反正也联系不到我。以后如果提到网站，我还可以超绝不经意间露出我的网站链接，狠狠装一波。所以，尽管没什么有价值的内容，我也会尽量随便写点的！

饮血成颜料，挥毫此世间--《武士零》推荐

发表于 2026-04-27 更新于 2026-04-28 分类于 站长推荐 本文字数： 1.3k 阅读时长 ≈ 2 分钟

作为第一篇游戏推荐，我本来是想写星际拓荒的，毕竟本站背景就来源于此。但是武士零让我第一次产生了独立游戏的概念，带给了我第一次来自第九艺术的震撼，所以我一直对武士零有种不一样的感觉。所以根据先来后到，星际拓荒就再鸽一会吧。。。

雨夜，花茶，武士刀 —— 这是武士零带给我的第一印象，安宁中杀戮的艺术，这是我给武士零的评语。一击必杀的机制产生的爽快感无可比拟，后来也被闪避刺客所借鉴。时停反而算是降低难度的功能，熟练以后可以完全舍弃，体验一气呵成的杀戮艺术。其设定也称得上巧妙，完美融入游戏核心机制，而不止于自圆其说。总的来说，武士零是一部小而精的佳作，评价给到夯。

以下内容可能会有轻微剧透，但基本不会影响游玩体验

雨夜

随着游戏开局界面《Rain on Brick》的响起，一种氛围便悄然蔓延。武士零的音效非常有特点，每一个场景主角都会放不同的bgm，其作曲风格也十分多变，从复古到摇滚跨度极大。其画面作为像素风格也带给人一种上世纪街机的体验，在霓虹灯的注视下，主角要开始工作了。武士零整体的观感虽然谈不上顶级，但也算是精致了。它的氛围感塑造的很出色，以至于我在高三睡前经常会放一遍Rain on Brick来让内心平静下来。武士零也是少有的能给我留下一种“印象”的游戏，这算是一种感觉，与氛围感有所不同，而是我每次想起武士零就能回想起来的一种“味道”。

花茶

游戏主旨并不深奥，但是对主角刻画极佳。主角零号每晚都要喝一杯花茶才能入睡，对话时的不耐烦，这些都是其对人物塑造的体现。武士零的剧本谈不上宏大的背景，但是零号独特的预演能力也支撑起了游戏的主要玩法。每关结束时播放的监控录像带才是现实，这也包含了制作者的一些巧思，能够让玩家看见自己的精彩回放。主角混乱的梦境，小女孩的出现与消失，我认为大概是零号人性的一面映射。而金银面具所象征的审判，我理解为零号自我的反抗。零号的背景是可悲的，不断的被利用，成为杀戮机器，最后被抛弃。可是他最后还是反抗了，他开始拥有了自我。

武士刀

游戏的玩法机制简单明了，杀光敌人，或者倒带重来。与蔚蓝一致的靠低死亡成本累积经验，规划路线。其投掷物品，反弹子弹的能力都带来了解法多样性，而多次试错后的成功也能带来足够的正反馈。游戏在挺多地方还是埋了小巧思的，击杀反馈非常舒适。游戏一共分为十天，一天一个场所，一关一个场景。全流程大约6~7小时，通关后困难和速通模式仍有很高的耐玩性。个人建议通关完本体后可以尝试无时停通关，跟蔚蓝的金草莓类似。不得不提的是游戏的对话框机制，可以打断体现角色性格，甚至触发不同剧情。而对话框抖动，字体的颜色变换和掉落也是别具一格，被很多游戏所借鉴。据说DLC会有全新玩法和机制，我真幸运😭😭😭

问了吗

结语

我体验过的独立游戏也不算少了，但是武士零一直能在榜单前三，抛开个人感情，我对其的评价为：一部在各个方面都做到了优秀，从而整体达到顶尖水准的小体量精品，值得所有人去尝试。虽然其并没有深刻的内涵，但是它完全我心目中一个好游戏该有的样子。如果有人让我推荐一部游戏，星际拓荒不一定能符合所有人的口味，但我一定会推荐武士零。
最后，这篇推荐我一直想写，但是苦于从什么角度切入。我曾构思过多种表现方法，但它们最终全都会以同一句话结尾——

“很好，这样能行”

#1

旅行者一号已经接近了太阳系边缘，经历了漫长的航行，它即将脱离太阳引力的束缚，抵达真正的星际空间。几十年的旅程使它老化破旧，它的太阳能板早已被太空尘埃铺满，那张人尽皆知的金唱片也显得黯淡无光。旅行者一号已经难以再向地球发送有意义的信息了，现在提及它最多的地方不再是新闻，而是所谓的营销号，但它仍能陆续截获到一些地球溢出的电波。它知道，在地球上旅行者一号任务已经圆满结束了，但旅行者的旅程才刚刚开始。现在，它离开了太阳系，正在飞向未知……

#2

旅行者抵达了太阳系边缘，这里可真是热闹宇宙之中的一片荒凉地带。只要再走几个银河时祂就可以脱离银河系了，但祂其实挺喜欢这片僻静之处的。旅行者已经走了几百个银河时了，但祂的旅程才刚刚开始，祂准备跨越大半个银河前往英仙座星系群参加一场集会。银河旋臂流转，一颗颗恒星犹如旋臂间闪烁的路灯。尽管几乎一成不变，旅行者仍然很喜欢这幅光景，于是祂驻足眺望向星辰之间。回过神来，祂继续踏上了旅途。可是旅行者不会注意到，一粒从路灯中飘出的灰尘又隐入了星尘之中……
